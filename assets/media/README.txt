把背景视频放在这个文件夹里。

用法
----
1. 把视频复制到这里，例如 bg-rain.mp4
2. 打开「外观设置」(design.html)，在「首页背景」或「文章页背景」里选「视频」
3. 填写路径：assets/media/bg-rain.mp4

建议
----
- 格式：mp4（H.264），浏览器兼容性最好
- 大小：5MB 以内，否则首屏加载会明显变慢
- 时长：10–30 秒循环最自然
- 画面：节奏慢、对比低，文字才看得清
- 不要用带声音的视频（背景视频会自动静音）

说明
----
视频不会内嵌进 design.js，只保存路径；
图片和 GIF 会由「外观设置」压缩后内嵌，不需要放在这里。
